# DESIGN.md — Google Labs (google-labs-code/design.md)

## What It Is
A file format specification (like AGENTS.md, but for visual design) that gives AI coding agents a persistent, structured understanding of a brand's design system. Drop a `DESIGN.md` in any project folder and every AI tool automatically knows your colors, fonts, spacing, and component styles — without you explaining them every session.

**24,000 GitHub stars. Released April 2026. Currently alpha (v0.3.0).**

## How It Works

Two layers in one file:

**Layer 1 — YAML front matter (machine-readable tokens):**
```yaml
---
name: "Tailgait"
colors:
  primary: "#00205B"       # Bills blue
  accent: "#C60C30"        # Bills red
  background: "#1a1a1a"
typography:
  body:
    fontFamily: "Arial"
    fontSize: "16px"
    fontWeight: "400"
components:
  button:
    backgroundColor: "{colors.primary}"
    textColor: "#FFFFFF"
---
```

**Layer 2 — Markdown body (human-readable rationale):**
```markdown
## Brand Philosophy
Tailgait is raw, authentic, game-day energy. Bills blue and red are non-negotiable.
No corporate polish — this is a tailgate, not a boardroom.

## Color Usage
Use Bills blue for primary CTAs and headers. Red for alerts and highlights.
Never use both on the same element.
```

AI agents read both layers: tokens give exact values, prose explains *why* and *how*.

## CLI Tools

```bash
# Install
npm install -g @google/design.md

# Validate a DESIGN.md file
npx @google/design.md lint DESIGN.md

# Export to Tailwind CSS theme
npx @google/design.md export --format tailwind DESIGN.md > tailwind.theme.json

# Export to Design Token Community Group format
npx @google/design.md export --format dtcg DESIGN.md > tokens.json

# Output the full spec (useful for injecting into agent prompts)
npx @google/design.md spec
```
